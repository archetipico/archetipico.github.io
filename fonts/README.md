# Fonts
- <code>MonoSubset.woff2</code> modified version of Red Hat Mono from <a href="https://github.com/RedHatOfficial/RedHatFont">its project</a>, reduced with <code>pyftsubset</code> to ASCII and <code>·</code>. "Red Hat" is a Reserved Font Name, so the modified font carries another name. Add any other character to the subset before using it on the page.
